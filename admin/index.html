Đăng nhập

Nội dung website, đơn hàng và lời nhắn được lưu trên Google Sheets. Nhập Khoá quản trị để bắt đầu.

Link Google Apps Script

Mặc định lấy từ assets/js/config.js của website.

Chỉ cần xem và xử lý đơn hàng? Quản lý đơn hàng → (dùng chung khoá)

Lấy khoá quản trị ở đâu?
  1. Mở Google Sheet làm database của website.
  2. Menu NMN Website → Thông tin kết nối → sao chép Khoá quản trị (và Link Web App nếu cần).
  3. Chưa có Google Sheet? Làm theo README → Google Sheets (database) — khoảng 5 phút.

Khoá chỉ lưu trên trình duyệt của bạn và chỉ gửi tới Apps Script của bạn. Nếu lộ khoá: menu NMN Website → Tạo khoá quản trị mới.
