NMN QUẢN TRỊ NỘI DUNG

Đăng nhập

Nội dung website được lưu trong repo GitHub. Nhập mã truy cập GitHub có quyền ghi vào repo để bắt đầu.

Nâng cao

Cách tạo mã truy cập (làm một lần)
  1. Mở GitHub → Fine-grained token mới (đăng nhập tài khoản sở hữu repo).
  2. Token name: ví dụ NMN CMS. Expiration: chọn thời hạn (ví dụ 90 ngày).
  3. Repository access: chọn Only select repositories → chọn repo nmn-website.
  4. Permissions → Repository permissions → Contents: chọn Read and write.
  5. Bấm Generate token, sao chép mã và dán vào ô phía trên.

Mã chỉ được lưu trên trình duyệt của bạn và chỉ gửi tới GitHub. Không chia sẻ mã cho người khác; nếu lộ mã, hãy xoá nó trong GitHub Settings.
